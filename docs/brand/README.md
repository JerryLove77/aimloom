# Aimloom mark: draft

**Status: a draft, not adopted.** Drawn by hand on 2026-11-02 for the ROADMAP item LOGO. It has
not been designed in Figma, and nothing in the App or on the website uses it yet: the App's icons
(`packages/app/src-tauri/icons/`) and the site's `favicon.svg` are unchanged.

## The idea

The name is *Aim + loom*. The mark is a crosshair woven like cloth:

- two **warp** threads (vertical, ink) and two **weft** threads (horizontal, Aimloom orange
  `#FF8000`) cross four times and pass alternately over and under, as threads on a loom do;
- the square the four threads enclose is the crosshair's **gap**, and the dot in it is the
  crosshair's **centre dot**;
- the threads run out to the edges like a crosshair's arms.

It reads as `#`, a weave and a crosshair, and it stays legible at 16 px because it is four strokes
and a dot.
