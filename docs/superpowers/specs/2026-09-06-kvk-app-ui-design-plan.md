## 1. 设计结论与范围

发行平台仅 Windows，运行要求为 PowerShell 7+。Mac 仅承担开发、浏览器预览和模拟目录测试，不实现或交付 Mac App。

推荐方向：**靶心工作台**。

以 Steam 上 KovaaK’s 的橙色靶心图标为主要识别来源，结合 McLaren 的石墨黑、局部切角和紧凑排版。大部分区域保持安静，橙色集中在当前选择、当前步骤和主要操作上。页面的第一任务始终是说明“将修改什么，以及如何恢复”。

本轮优先设计安装向导与备份恢复，不增加产品功能范围。现有 App 的主题、音效、准星管理页只规划风格延展，不把素材预览、逐项参数编辑或宣传网站并入 v0.1.x 首轮交付。

| 优先级 | 页面／场景 | 交付深度 |
|---|---|---|
| P0 | 选择位置、选择内容、确认安装、执行与结果 | 完整布局、文案、组件与状态规格 |
| P0 | 备份列表、恢复预览、冲突处理、中断恢复 | 与安装同等级的可用性与视觉完整度 |
| P1 | 使用帮助、版本信息 | 紧凑页面，围绕路径、备份和故障说明 |
| 后续 | 主题、音效、准星管理 | 记录页面骨架；不承诺首版提供编辑／预览能力 |

## 2. 先观察品牌，再选择设计语言

### 2.1 Steam 图标：主要来源

已实际打开 [KovaaK’s Steam 商店](https://store.steampowered.com/app/824270/KovaaKs/) 和 [Steam 社区中心](https://steamcommunity.com/app/824270)，并查看社区页面实际引用的 32 × 32 应用图标。

- 方形图标为深色底，主体是暖橙色靶心／同心轮廓，带指向靶心的箭形细节。
- 核心识别是圆心、环形层次和方向性，不是一个字母 K。
- 商店横幅是橙色 KovaaK’s 字标，背景也使用同心圆与细密纹理；横幅与方形应用图标分开观察，不混作同一个资产。
- UI 提取“聚焦到中心”的关系，用在当前步骤和完成状态；不把小尺寸图标放大成背景，也不凭它声称测出了官方品牌色。

图标来源：[Steam 页面引用的应用图标](https://shared.fastly.steamstatic.com/community_assets/images/apps/824270/ed2df8e3157c3fe9b62d0b72bdcd20d4e674be32.jpg)。此链接作为设计参考，运行时离线界面不依赖远程图片。

### 2.2 McLaren：辅助来源

[McLaren MCL40 官方发布页](https://www.mclaren.com/racing/formula-1/2026/mcl40-launch/) 及 [2026-02-09 涂装公告](https://www.mclaren.com/racing/formula-1/2026/mclaren-racing-reveal-livery-for-the-mclaren-mastercard-formula-1-teams-2026-challenger/) 明确使用 papaya、anthracite 与少量 teal 的组合。页面实看还可见清楚的大字层级、宽留白及局部切角。

对本 App 的转译：深石墨表面、橙色功能焦点、少量有方向的几何边缘。保留 KovaaK 靶心作为主语汇；McLaren 的青色不升级为第二品牌主色。不引入赛车照片、车队标志、赞助商条带、虚构遥测图或“圈速”等与配置操作无关的文案。

### 2.3 当前产品 UI 参考

没有可验证的“最先进 UI”排名。本方案借用近期优秀产品已公开的设计方法，而不是把某种视觉效果称作行业标准。

| 来源 | 可观察的做法 | 本项目采用方式 |
|---|---|---|
| [Linear UI refresh，2026-03-12](https://linear.app/changelog/2026-03-12-ui-refresh) | 统一页头与导航，降低侧栏亮度，调整图标，帮助扫描和保持焦点 | 固定页面框架；主内容明亮，导航克制；同一操作在所有页面保持同名、同位置 |
| [Microsoft Fluent 2 Layout](https://fluent2.microsoft.design/layout) | 用空间、对齐和网格建立层级，并随窗口调整 | 桌面双栏、窄窗口单栏；把覆盖说明和下一步放在稳定的位置 |
| [Microsoft Fluent 2 Motion](https://fluent2.microsoft.design/motion) | 动效服务于状态变化和导航关系 | 快速切页、清晰的选择反馈和真实处理状态；减少持续装饰动画 |

上述来源支持的是具体做法。下文配色数值、尺寸、靶心步骤图形和页面构图均为本项目的设计提案。

## 3. 现有 App 基线与要解决的问题

已读取根目录 [DESIGN.md](../../../DESIGN.md)、App.tsx（原 checkpoint：`b2099e7:packages/app/src/App.tsx`）、index.css（原 checkpoint：`b2099e7:packages/app/src/index.css`），并运行现有 `dev:web`，观察桌面页面。该预览使用 MemoryAdapter 测试数据，不能作为真实安装或素材播放证据。

| 现状 | 对新方案的影响 |
|---|---|
| 已有黑橙基调、统一按钮类、目录定位和状态提示 | 延续品牌基础与共用控件思路，避免另起一套不相关的风格 |
| 探索栏、配置档、素材标签、列表与备份同处一个外壳 | v0.1.x 按用户任务组织；安装和恢复成为两个明确入口 |
| 首屏素材列表很长，未选素材时右侧大面积空白 | 安装页先做类别选择；文件清单需要时再展开 |
| 探索区小字较密，背景光晕和橙色区域较多 | 提高中文正文可读性，减少非操作区域的橙色占用 |
| 旧桌面文案包含“不动手感”“出厂快照” | 新安装器必须使用“默认保留个人设置”“首次保护状态”，与可选 Primary 覆盖和实际恢复语义一致 |

本轮不改根目录 DESIGN.md 的正式规范及 CSS。新提案在确认后，与对应运行时 token 和共用组件同步迁移；旧桌面页的规则不因本文自动改变。

## 4. 方向比较

| 方向 | 特征 | 取舍 |
|---|---|---|
| **A · 靶心工作台（推荐）** | 深石墨、暖橙、同心弧线、明确的四步操作 | 最贴近 Steam 图标，兼顾品牌识别和配置操作的可读性 |
| B · 赛车维修区 | 更大的橙色块、斜切构图、压缩大字、强方向线 | 赛车感鲜明，但容易掩盖 KovaaK 识别，也更容易让确认页显得拥挤 |
| C · 轻透明桌面工具 | 浅层透明面板、柔和阴影、橙色点缀 | 轻盈，但对背景、渲染框架和性能更敏感；靶心辨识度较弱 |

采用 A；从 B 只提取局部切角与数字排版，从 C 提取层级克制，不采用大面积模糊玻璃。大胆之处集中在一个原创的“靶心步骤标”，其余控件优先遵循熟悉的桌面操作方式。

## 5. 视觉系统提案

### 5.1 配色

延续现有 `--kvk-accent: #FF8A2E` 作为 UI 暖橙；它是产品选色，不标称 Steam 或 McLaren 的官方色号。深灰有轻微冷调，与暖橙形成分离。

| 角色 | 提议值 | 用途 |
|---|---|---|
| 背景 | `#0D0D10` | App 主背景、导航底色 |
| 表面 | `#151519` | 主内容面板 |
| 抬高表面 | `#1D1D23` | 可选卡片、弹层、输入区域 |
| 主文字 | `#F4F4F5` | 标题、主要信息 |
| 次要文字 | `#A9A9B2` | 说明、路径辅助文字 |
| 品牌橙 | `#FF8A2E` | 当前步骤、选中标记、主按钮 |

补充语义 token：弱分隔线 `#303038`；可交互边界 `#70707C`；辅助文字 `#8A8A95`；橙底文字 `#17120D`；焦点环 `#FFC078`；成功 `#70D69B`；注意 `#E8C36A`；错误 `#FF7B80`。状态一律同时配图标和文字，不只换颜色。

普通页面以暗色表面为主，橙色可见面积控制在约 5–10% 的设计目标内。完整设置风险区使用柔和注意色与清楚的说明，不让它和橙色主按钮争夺注意。

已计算不透明颜色的对比度：主文字／表面约 16.57:1，次要文字／表面 7.81:1，橙底深色按钮文字 7.91:1，辅助文字／表面 5.33:1。这是 token 级检查；最终混合、悬停和禁用状态仍须在渲染后验证。

### 5.2 字体与中文

- 中文正文：`Microsoft YaHei UI` → `Microsoft YaHei` → `PingFang SC` → 系统无衬线。
- 英文品牌副标题与步骤数字：`Bahnschrift` → `Segoe UI` → 系统无衬线；只在简短标题和数字上使用其紧凑感，不拉伸中文。
- 文件路径：`Cascadia Mono` → `Consolas` → 等宽字体，中文回退至正文字体。
- 字体优先使用本机可用字体；缺失时有明确回退，离线启动不等待字体下载。

| 层级 | 字号／行高 | 字重 |
|---|---|---|
| 页面标题 | 28 / 36 | 600–700 |
| 模块标题 | 18 / 26 | 600 |
| 正文、表单和按钮 | 15 / 24 | 400／600 |
| 辅助说明与文件清单 | 13 / 20 | 400 |
| 当前步骤数字 | 24 / 28 | 600 |

中文不使用全大写式字距或整句斜体。风险说明保持正文大小；按钮写“确认并安装”“查看备份”，不写模糊的“启动”“GO”。

### 5.3 形状、图案与标志性细节

**靶心步骤标**：在侧栏顶部放置 64 × 64 的四段环形标记，中心显示当前步骤 `2 / 4`。四段对应真实的四个步骤，当前段为橙色，已完成段带完成标记；它不代表文件复制百分比。窄窗口改为横向步骤条。

同心圆图案只在侧栏品牌区域使用一个低对比、局部裁切的静态弧线组，最多三条弧线，透明度约 4%。文字、文件表格和确认区不铺纹理。

McLaren 借鉴限于当前导航标记末端和标题下短横条的一处约 12° 切角。按钮、输入框仍保留完整矩形命中区域，不为了切角裁掉焦点环。卡片圆角 12，控件圆角 8，标签圆角 4；阴影只帮助弹层分层。

图标采用一致的 20px 线性图标，笔画约 1.75px。类别图标分别表达主题、声音和准星；不用 emoji 或赞助商式图块。App 品牌区显示项目名称“KVK Config / 配置管理”，靶心图形采用原创结构，避免把本工具呈现为车队或游戏官方客户端。

### 5.4 动效

悬停／按压 100–140ms，切页淡入 160–200ms；位移不超过 6px。当前步骤切换时只更新环段和内容焦点，不做旋转仪表盘。完成时允许一次 180ms 的中心勾选出现。

尊重减少动态效果设置：移除位移和弧线过渡，保留即时状态变化。安装过程不显示模拟速度、预计剩余时间或假百分比；没有真实进度事件时使用阶段文字和不定进度指示。

## 6. 页面结构与布局

默认以 **1120 × 760 逻辑像素** 设计，主工作区最大宽度 1200。左侧导航 200，内容内边距 28，模块间距 24，控件间距 12。确认页的大屏布局为主内容 + 280px 摘要栏。

顶层仅有“安装配置”“备份恢复”“使用帮助”。不新增空的总览页、统计仪表盘或账号入口。版本信息放在侧栏底部。

### 页面 A：选择位置

标题“先确认游戏和配置包的位置”。游戏目录卡在上，配置包卡在下，均展示完整可复制路径和“更换”按钮。常见目录检测完成后显示文字状态；有多个候选时列出单选项，不自动决定。

未找到时显示“没有检测到游戏目录，请选择安装位置”，提供系统文件夹选择器和手输路径方式。选择器取消时保留已有选择。路径校验失败在字段旁说明修正方法。右侧为简短的操作说明：选择内容 → 修改前备份 → 按需恢复。

主按钮“下一步：选择内容”。位置可确认后才启用；无法继续时直接给出原因。改变任一根目录都会使旧预览失效，重新检查内容和备份归属。

### 页面 B：选择内容

前三张同规格卡片是主题、音效、准星；显示图标、类别名、包内数量与一句用途。首版不在卡片中伪装素材预览。整个选择区可点击，具有真正的复选框语义和键盘行为。

下方“可选配置”是独立区域：界面、配色、完整设置均默认关闭。开启完整设置时就地展开覆盖灵敏度等说明，核对页再汇总，不重复弹出多层确认框。

没有该类别时显示“包内无此内容”，不可选；未知文件可查看跳过列表。全部取消时提示至少选择一类。返回、前进保留当前选择。

### 页面 C：确认安装

```text
┌────────────────────────────────┬────────────────────┐
│ 核对这次安装                    │ 本次将安装         │
│ 游戏目录  … [查看完整路径]       │ 主题 / 音效 / 准星 │
│ 配置包    …                    │                    │
│                                │ 个人设置：保留     │
│ 新增 n  / 覆盖 n / 跳过 n       │ 备份位置：…        │
│ [全部] [仅覆盖]  搜索文件… [×]  │                    │
│ 操作  文件名   目标路径         │ 修改前自动备份     │
│ 覆盖  …        …               │                    │
│ 新增  …        …               │ [确认并安装]       │
│ [上一页] 第 1 / n 页 [下一页]   │                    │
└────────────────────────────────┴────────────────────┘
```

默认突出覆盖数量；文件列表按操作和路径排序，30 条一页，支持本地搜索及“仅覆盖”过滤。路径可换行或展开复制，不能只靠悬停看完整值。更改搜索和过滤不改变安装选择范围，摘要继续显示整批数量。

摘要中的“个人设置：保留”必须来自实际选项；选择 Primary 后改为“完整设置：整体替换”，旁列灵敏度、DPI、FOV 提醒。新增、覆盖、跳过和预计备份路径来自引擎计划。

最终按钮“确认并安装”就是本批的明确确认，不再叠加一个内容相同的普通确认框。预检错误显示具体文件和返回调整入口。安装前发生源文件或目标变化时要求重新核对，禁止沿用旧计划。

### 页面 D：执行与结果

执行中维持同一页面骨架，展示“准备文件／保护原始文件／安装文件／校验结果”的实际阶段。只有数据接口报告了真实完成数量，才显示 `已处理 n / m`；它与侧栏四步标记分开。

禁止重复安装和切换目录。继续显示游戏状态、备份位置与“请保持窗口开启，暂勿启动游戏”。窗口仍需响应；用户要求关闭时说明当前阶段的影响。在引擎具备安全取消协议前，不提供“取消安装”按钮。

完成页显示“文件安装完成”，列出本批结果和备份编号；提示“进入游戏选择主题、绑定音效和选择准星”。主操作“完成”，次操作“查看备份”“打开备份文件夹”，不默认启动游戏。

失败必须分成三类：预检未写入、安装失败且已回滚、仍有文件待恢复。待恢复状态常驻页面并提供“进入恢复”，不能用短暂 toast 代替，不能把进程结束等同于恢复成功。

### 页面 E：备份恢复

左侧是备份记录，右侧是选中记录详情；默认最近一次有效安装，待恢复批次置顶。每条显示时间、类别、操作结果和简短编号，不只显示 hash。首次保护状态作为独立入口，解释为“各文件第一次被工具修改前的状态”。

选择记录后先生成恢复预览：将恢复、删除、跳过的文件及冲突数。主按钮使用“确认恢复”；发生外部修改冲突时，先在独立确认面板展示具体文件，再让用户明确选择“另存当前文件并继续恢复”。不得预先勾选允许冲突。

搜索和分页使用与安装清单相同的模式。没有备份时提供“前往安装配置”；备份损坏显示原因并停止；发现中断批次时先处理恢复，不能进入新安装。恢复完成返回记录详情并显示结果。

### 页面 F：使用帮助

只保留与首版直接相关的内容：如何找到游戏、安装后如何选用素材、默认保留哪些设置、备份在哪、如何恢复、启动受阻怎么办。说明随包离线可读，外部反馈链接明确标识。错误页可以直接进入对应帮助段落。

## 7. 跨页交互与可访问性

| 状态 | 统一行为 |
|---|---|
| 正常／悬停／焦点／按下 | 表面轻微变化、明确焦点环；不只靠发光表达可点击 |
| 禁用 | 保留可读标签，说明不可用原因，不响应提交 |
| 扫描／校验中 | 固定尺寸的状态区域，避免按钮位置跳动；旧结果不可误当成新结果 |
| 空内容／无结果 | 区分没有素材与搜索无匹配；保留更换包／清空搜索入口 |
| 游戏运行 | 可浏览和选择；写入前要求退出游戏，重新检测后继续，不强制结束游戏 |
| 计划失效 | 保留选择，重新生成清单并再次确认，不自动提交新计划 |
| 中断／待恢复 | 常驻提示、恢复优先；所有页面共享同一状态来源 |
| 本地离线 | 核心安装、帮助和恢复可用；外链失败不影响已有文件操作 |

- 键盘顺序沿视觉顺序；步骤切换后焦点移到标题，表单错误后移到首个错误字段。返回保留输入。
- 复选框、按钮、标签页使用平台对应的可访问语义。模态确认有标题、焦点约束与关闭后焦点恢复，默认焦点落在较安全的操作上。
- 搜索支持中文输入法组合输入；非空时提供明确的清空按钮。路径、搜索和待选文件保留在本地会话内，不写进 URL。
- 主要按钮高度至少 44，常规控件至少 40；控件边界与焦点可辨认，状态不只依靠红绿差异。
- 安装结果和错误有持久文本；进度播报按阶段或有节制的数量变化更新，避免逐文件轰炸读屏。
- 对比度目标为 WCAG 2.2 AA；最终实现需覆盖高对比模式和减少动态效果设置。

## 8. 窗口尺寸与滚动

- ≥ 1100px：200px 导航 + 内容；确认页与恢复页可采用双栏。
- 900–1099px：导航缩至 176px，确认摘要移至清单上方，类别卡片改为两列。

- 重点验证 1120 × 760、1280 × 720 和 900 × 640，以及 Windows 125%、150%、200% 缩放下的逻辑可用空间。

## 11. 设计验收标准

1. 首次使用者能在首屏找到游戏目录、配置包和下一步；不会把“目录已找到”理解成“已经安装”。
2. 任一安装确认页都能直接回答：选了哪些类别、会覆盖多少文件、是否改个人设置、备份放在哪里。
3. 橙色靶心与深色结构形成一致识别；去掉赛车装饰后仍能认出是 KovaaK 配置工具。
4. 完整设置覆盖说明、恢复删除范围、外部修改冲突在窄窗口和缩放后仍可读、可操作。
5. 处理过程不假死、不重复提交；没有数据时不显示假进度；中断后不会误报全部成功。
6. 安装完成页明确提示游戏内选用步骤；恢复完成页依据引擎实际结果报告。
7. 默认素材安装保留个人设置；备份、冲突与恢复规则不因换 UI 而变化。
8. 用户可只用键盘完成目录输入、类别选择、核对与恢复；弹层关闭后焦点合理返回。
9. 五组主画面、关键失败状态、真实 Windows 渲染与引擎行为都有单独证据，才能将 UI 待办勾为完成。
